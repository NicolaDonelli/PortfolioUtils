portfolio_utils.download.source module

Verified public Investing.com ETF pages and historical-data endpoint.

Verification date: 2026-10-31, using public curl_cffi GET requests only. No account, login flow, cookies, or protection bypass is used. Site pages returned 200 with a Chrome-impersonating curl_cffi session; direct Playwright navigation to a detail page returned 403.

Undocumented endpoints observed and used by InvestingComSource:

  • ETF index: GET https://www.investing.com/etfs/; no query parameters and no application-supplied headers (curl_cffi Chrome impersonation defaults). Response is HTML with links to category pages.

  • Category pages: GET https://www.investing.com/etfs/{category}, where the index exposed usa-etfs, world-etfs, major-etfs, and cannabis-etfs; no query parameters and no application-supplied headers. HTML rows contain tr#pair_<id>, a span[data-name][data-id], a symbol cell td.left.symbol[title], and an ETF detail link. At verification, responses had 1000 USA rows, 708 World rows, 37 Major rows, and 12 Cannabis rows. No pagination links were found in these observed HTML pages. The category set and contents may change; enumeration is limited to root-linked categories and explicit pagination links and is not claimed to be an exhaustive Investing.com catalog.

  • ETF detail pages: GET https://www.investing.com/etfs/{slug}; no query parameters and no application-supplied headers. The observed Next.js payload included props.pageProps.identifiers.instrument_id and type="etf". Category-row identifiers are used directly; detail pages are not fetched per ETF.

  • Historical prices: GET https://api.investing.com/api/financialdata/historical/{instrument_id} with start-date=YYYY-MM-DD, end-date=YYYY-MM-DD, time-frame=Daily, and add-missing-rows=false; required application header domain-id: www. Response is JSON with data and summary; daily data uses rowDateTimestamp, last_openRaw, last_maxRaw, last_minRaw, last_closeRaw, and volumeRaw. Rows are descending. A wide SPY request returned 4999 earliest records; the adapter advances from the latest returned date plus one day to retrieve subsequent records.

Fixtures in tests/resources/investing/ contain small anonymized examples. There is no general search endpoint: identifier lookup scans the observed root-linked category tables, so an identifier outside those categories can remain unresolved.

Module contents

Public facade for sequential Investing.com ETF historical downloads.

The public HTML and historical endpoint are implemented from the verified evidence documented in portfolio_utils.download.source. Catalog enumeration follows categories linked by the index and explicit pagination links; completeness beyond those observed pages is not claimed.
