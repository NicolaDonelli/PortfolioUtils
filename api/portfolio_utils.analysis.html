portfolio_utils.analysis.backtest.walk_forward_backtest(returns: pd.DataFrame, optimizer: PortfolioOptimizer, *, estimation_window: int, rebalancing_frequency: str, transaction_cost_bps: float) → BacktestResult

Backtest a strategy with estimates lagged by one return observation.

At each rebalance date, the optimizer receives the immediately preceding estimation_window rows. Weights first apply to that date’s return. Trading costs are basis points multiplied by absolute one-way turnover.

Parameters:

  • returns – Complete, aligned simple-return panel with dated rows.

  • optimizer – Callable accepting historical data and returning an optimization result or weight series.

  • estimation_window – Number of preceding returns used at each rebalance.

  • rebalancing_frequency – Pandas period such as "M" or "Q".

  • transaction_cost_bps – Linear cost per unit of turnover, in basis points.

Raises:

RuntimeError – If the optimizer fails or returns invalid weights.

Returns:

Net portfolio returns, applied weights, turnover, and caveats.

  • risk_aversion – Positive quadratic utility and Black-Litterman risk-aversion coefficient.

portfolio_utils.analysis.prices_to_returns(prices: DataFrame, *, method: Literal['simple', 'log'] = 'simple', alignment_policy: str = 'inner', ffill_limit: int | None = None) → DataFrame

Calculate simple or log returns after explicit calendar alignment.

Simple returns are appropriate for aggregation across assets; log returns are additive through time. The first undefined return is removed explicitly. No backward filling is performed.

Parameters:

  • prices – Wide close-price panel.

  • method – Return convention, either "simple" or "log".

  • alignment_policy – Calendar policy passed to align_prices().

  • ffill_limit – Maximum forward-fill distance when using "ffill".

Raises:

ValueError – If prices or options are invalid, or fewer than two aligned prices remain.

Returns:

Wide return panel with its first undefined row removed.

>>> import pandas as pd
>>> prices = pd.DataFrame(
...     {
...         "a": [
...             100.0,
...             110.0,
...             99.0,
...         ]
...     },
...     index=pd.date_range(
...         "2024-01-01",
...         periods=3,
...         freq="D",
...     ),
... )
>>> prices_to_returns(
...     prices
... )["a"].round(
...     2
... ).tolist()
[0.1, -0.1]

portfolio_utils.analysis.walk_forward_backtest(returns: pd.DataFrame, optimizer: PortfolioOptimizer, *, estimation_window: int, rebalancing_frequency: str, transaction_cost_bps: float) → BacktestResult

Backtest a strategy with estimates lagged by one return observation.

At each rebalance date, the optimizer receives the immediately preceding estimation_window rows. Weights first apply to that date’s return. Trading costs are basis points multiplied by absolute one-way turnover.

Parameters:

  • returns – Complete, aligned simple-return panel with dated rows.

  • optimizer – Callable accepting historical data and returning an optimization result or weight series.

  • estimation_window – Number of preceding returns used at each rebalance.

  • rebalancing_frequency – Pandas period such as "M" or "Q".

  • transaction_cost_bps – Linear cost per unit of turnover, in basis points.

Raises:

RuntimeError – If the optimizer fails or returns invalid weights.

Returns:

Net portfolio returns, applied weights, turnover, and caveats.
